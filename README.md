# Lodge
Lodge｜Room-first multi-agent coding workspace. 房间才是本体，一室一任务，隔离交付、可验可溯。

> 一寮承事，灵侣偕居，功成俟鉴

**Room-first multi-agent workspace**
Lodge 以寮（Lodge）为一等本体，席位驻于寮内；
对话只是寮内日志，目标、席位、worktree沙箱、验收证据全部附着在寮上。

- 🏠 Lodge = 独立任务房间（本体）
- 🧑‍💻 Seat = Agent席位
- ✅ acceptance_cmd：可执行命令作为验收证据
- 🛡️ Worktree隔离，防止互相篡改产出
