# Lodge

> 房间（Room）是本体，成员（Member）是房间里的人，Bot 是这个人现在的身体。
> 一条 Assignment 一条记录，状态往前走，证据不搬家。

Lodge 是本地优先、房间优先的工作台。说清一件事，房间替你留下目标、过程、结果和证据；换成员、换引擎、换模型，房间还在。

## 现在能做什么

- **一句话开房**：说清目标，确认成员和验收方式后开工。
- **两套房型**：聊天室只讨论、收结论；工作室分步执行、独立复核、人签字、可交付。
- **真实执行**：跑在本机的 CLI 上；git 仓库用 worktree，普通目录原地修改；多执行并行后集成。
- **证据验收**：验收命令、退出码、diff 和改动文件；没有 PASS 不能签字。
- **权限与审批**：写工具按成员拒绝；对外部动作挂起等人批准。
- **交付可带走**：交付卡、证据、一次 commit，都留在房间里。
- **桌面**：macOS Electron ad-hoc zip；基座单独运行，内置 runtime 随 app 分发。

## 为什么不一样

1. **房间是本体**：目标、阶段、证据、结论、commit 都在房间里；换成员或引擎，记录还在。
2. **验收是证据**：模型自述不算通过；命令、退出码和人的签字才算。
3. **交接有记录**：谁把什么交给谁、交付了什么、证据是什么，一条 Assignment 说完。
4. **本地优先**：用你自己的仓库和已登录的 CLI，不把工作搬到云上。
5. **诚实边界**：没有第二引擎就标独立性降级；不是通用沙箱、没有自动更新，就不说。
